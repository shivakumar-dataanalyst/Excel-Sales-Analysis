## Project Overview

This project analyzes sales data using Microsoft Excel.

## Tools Used

- Microsoft Excel
- Excel Formulas
- Charts
- Data Cleaning

## Excel Functions Used

- SUM
- AVERAGE
- MAX
- MIN
- COUNT
- IF
- COUNTIF
- COUNTIFS
- SUMIF
- SUMIFS
- ROUND

## Key Analysis

- Total Sales
- Average Sales
- Highest and Lowest Sales
- Regional Sales
- Category-wise Sales
- Sales Performance

## Objective

The objective of this project is to demonstrate basic
Excel data analysis and formula skills for a Data Analyst role.
